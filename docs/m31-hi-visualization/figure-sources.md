# M31 visualization figure provenance

[English specification](README.md) · [中文图件来源](figure-sources.zh-CN.md)

The WebP panels are included with the specification. DualVectra paths below identify the historical source assets and implementation records. The figures can be viewed directly from this repository. Compare historical cutouts with the final catalogue by sky position and velocity. Pixel indices are specific to the source FITS.

## Figure 1. M31 map and Bubble 31 concept

- The M31 panel uses the original CARTA preview at `assets/cover/carta-references/c24full32_pbmergedD_jcomb_step240_k0000_0499_mom0_contsub_linefree_n4a2m30_full500.fits-image-2026-08-17-00-16-16.png`. It was resized proportionally with the sky axes and display colour bar intact. Locator coordinates for the prototype should come from the registered map WCS.
- The Bubble 31 panel uses `outputs/bubble31_blender/bubble31_shell_macro_v4_preview.png`, generated by `script/build_bubble31_shell_geometry.py`. Projected intensity guided surface detail and transparency. The shell depth, near-side opening and lighting were specified for the concept. Figures 2–4 use geometry constructed in observed PPV coordinates.

## Figure 2. Bubble 104 route comparison

- The source is the primary HDU of the historical `bubble104.fits` with SHA-256 `b9a746bef8b0d2c173b4bef3c33ced7154a09a6adcd0ead4b2337d540a9184c2`. Its shape is `[89,128,128]` in velocity, y and x, with intensity in Jy/beam, a 60 arcsec beam and a VRAD axis in the LSRK frame. The native spacing is about 1.649 km/s. The panels use zero-based channels 41, 37 and 33 at −92.03, −85.43 and −78.84 km/s.
- Route A uses the `bubble104_recommended` model under `outputs/nine_bubbles_recommended_v1/`. The stem identifies the preview and run record. The corresponding assets directory contains the `_cavity_F0p30.obj` mesh, `_cavity_manifest.json` and `_cavity_qa.png`. Settings were `surface=0.30`, `roundness=0.80` and target `depth=1.00`.
- Route B uses the `bubble104_outer_ridge_closed_v1` model under `outputs/all_outer_ridge_v1/`. The stem identifies the preview and run record. The corresponding assets directory contains the `_envelope.obj` mesh, `_envelope_manifest.json` and `_envelope_qa.png`. The ridge prior radii were (21.6, 21.6) pixels, with a threshold fraction of 0.18, `hybrid` closure and target `depth=1.03`.
- Both mesh origins correspond to source pixel (59, 69). The overlays undo each mesh's velocity stretch and restore its velocity zero point from the source window and manifest. Route A uses the median of the native channels in its analysis window. Route B uses the peak-channel velocity. Intersections with the three channel planes are drawn over the native cutout with a shared linear intensity scale and no additional smoothing. The Blender panels have independent framing and the highlights come from the lighting and materials. CAND021 identifies the object in the final catalogue. Register a new cutout using its own WCS.

## Figure 3. Bubble 54 velocity endpoints

- The source is the primary HDU of the historical `bubble54.fits` with SHA-256 `7ca9822aeafd9d5c719d60c72d5ca81d4fff9577de6e8eb7217f6fae012583c7`. Its shape is `[56,128,128]`, with intensity in Jy/beam, a 60 arcsec beam and VRAD in the LSRK frame. The native spacing is about 1.649 km/s. The mesh centre corresponds to about 00h40m20.70s, +41°02′38.4″ in the cutout WCS, matching **CAND067**. CAND054 is a different object with the same numerical bubble ID.
- Route A uses `bubble54_recommended_cavity_F0p30.obj` under `outputs/nine_bubbles_recommended_v1/bubble54_recommended_assets/` and its cavity manifest and QA image. Settings were `surface=0.30`, `roundness=0.50` and target `depth=1.00`. Native segmentation retained the channels centred at −390.45 and −388.81 km/s.
- Route B uses `bubble54_outer_ridge_closed_v1_envelope.obj` under `outputs/all_outer_ridge_v1/bubble54_outer_ridge_closed_v1_assets/` and its envelope manifest and QA image. Settings were a threshold fraction of 0.18, `hybrid` closure, target `depth=1.03` and a six-channel limit on extending the catalogue association interval. The selected interval is −408.59 to −380.56 km/s. The manifest flags the high-velocity end as association-limited. The constructed envelope extends beyond that endpoint.
- Both meshes were transformed back to native PPV as in Figure 2 and intersected with the zero-based y=60 plane. The thin vertical lines mark native channel centres. Each blue band spans one native channel spacing. The light dashed line marks the association-limited endpoint. The overview and detail use the same linear intensity scale.

## Figure 4. Bubble 32 four views

- The source images are `bubble32_view_000.png`, `bubble32_view_090.png`, `bubble32_view_180.png` and `bubble32_view_270.png` under `outputs/outer_ridge_final118_s3v6_v2/packages/selected_9_four_views_v1/images/`. All four SHA-256 hashes matched `four_view_render_manifest.json`. The source frames are 1100 × 1100, with the same crop and resizing applied to each.
- The scene uses `bubble32_outer_ridge_closed_final118_v1` (CAND074), with threshold fraction 0.18 and `hybrid` closure. The manifest records a rotation about world Z (the displayed Dec axis) with fixed camera and lights. The geometry was marked `review` because a constraint on departures from the prior was active at more than 10% of the azimuths. The render status was `success`.
- The batch overview is `outputs/outer_ridge_final118_s3v6_v2/reports/final118_outer_ridge_preview_report_12_per_page.pdf`. The four-view manifest records the actual views shown here.

## Figure 5. Proposed points, edges and sampling

The panels use a deterministic two-dimensional synthetic emission field and random seed 415. Each panel includes the same baseline samples. The third panel adds samples near the synthetic shell. Solid and dashed traces represent the near and far sides in the schematic. This figure illustrates layer design and sampling. It was generated from the synthetic field before any 3D compositing or engine import.
