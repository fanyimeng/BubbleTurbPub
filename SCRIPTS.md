# Final paper figures

Run `python plot/build_paper_figures.py <figure>` from the repository root.
Use `1`–`4` for main figures and `S1`–`S14` for supplementary figures.
Generated outputs go to `output/`; reference PDFs are stored in `plot/`.

Figure 3 is one energy-budget panel. Figure 4 contains the panels generated by
`dot_e_vs_turb.py` and `dot_e_vs_timescale_insets.py`; it is not the earlier
four-panel mainchart. S13 uses `dot_e_ratio_panels_hi.py`.

For S11 the driver adds `--overwrite`. When calling that script directly, use
`--overwrite` after the first run. Its reference PDF is `plot/Supplementary_Figure_11.pdf`.

S2 fixes the paper's PP/PV colours, linear normalization, `window_p05p95`
clipping, angle overlays and 400 dpi raster components. Figure labels 10/17
correspond to historical catalogue IDs 115/108. Subcube WCS centres are checked.
See `plot_paper_pv_examples.py --help`; cutting new subcubes requires the explicit
`--allow-cut-from-full-cube` option.

S3 uses the final diagnostic's stored plotting values, error bars and membership;
it does not rerun classification.
Its purpose and presentation differ from the fiducial Figure 3.

S4 uses the final 118-object axis ratios and matches the histogram counts in
`Supplementary_Data.xlsx`. Its refreshed example differs from the older static
PDF that used the historical catalogue; see [RELEASE_NOTES.md](RELEASE_NOTES.md).

S5 recomputes densities against the full final-118 interior mask and checks them
against the released catalogue. Its generated table goes to `output/derived/`,
leaving the released input unchanged.

PDF composition preserves vector panels. Font rendering and PDF metadata can
vary by library version; numerical agreement is assessed against the released
catalogue and submitted workbooks.
